Conversas sobre desenvolvimento de software

Times de tecnologia falam inglês o tempo todo — pull requests, bugs, deploys, code review e alinhamentos técnicos. Este contexto reúne frases comuns em chats e calls de desenvolvimento, para quem já programa e quer participar de discussões sem travar nas palavras do dia a dia.

Você praticará pedidos de revisão, reporte de problemas e combinação de próximos passos com tom direto e colaborativo. Ao ouvir, identifique verbos de ação — fix, merge, deploy, investigate. Repetir esses verbos em frases completas acelera a fluência técnica mais do que memorizar glossários isolados.

Have you pushed your changes?

Você deu push nas suas alterações?

Yes, I pushed to the feature branch.

Sim, dei push para a branch da feature.

We need to refactor this module. It is too complex.

Precisamos refatorar este módulo. Está complexo demais.

Can you review my pull request?

Pode revisar meu pull request?

Sure. I will take a look this afternoon.

Claro. Darei uma olhada esta tarde.

She fixed the bug. The build is green now.

Ela corrigiu o bug. O build está verde agora.

What is the status of the deployment?

Qual é o status do deploy?

It is in progress. Should be done in ten minutes.

Está em andamento. Deve terminar em dez minutos.

I am writing unit tests for the new API.

Estou escrevendo testes unitários para a nova API.

Did you run the tests locally?

Você rodou os testes localmente?

Yes, all tests pass. The pipeline should be fine.

Sim, todos passam. O pipeline deve estar ok.

He suggested we use a different library.

Ele sugeriu usar uma biblioteca diferente.

How do we handle the migration?

Como lidamos com a migração?

We will run it in stages. Rollback plan is ready.

Rodaremos em etapas. Plano de rollback pronto.

The API is returning 500. We are investigating.

A API está retornando 500. Estamos investigando.

Who owns the authentication service?

Quem é dono do serviço de autenticação?

The platform team. We need to talk to them.

A equipe de plataforma. Precisamos falar com eles.

She merged the PR. It is in main now.

Ela deu merge no PR. Está na main agora.

Do we have documentation for this?

Temos documentação para isso?

Not yet. I will add it before we ship.

Ainda não. Adicionarei antes de enviarmos.

We are moving to microservices. Phase one is done.

Estamos migrando para microsserviços. Fase um feita.

What is the error in the logs?

Qual é o erro nos logs?

Null pointer in the user service. Line forty-two.

Null pointer no serviço de usuário. Linha quarenta e dois.

He is pairing with someone on the frontend.

Ele está fazendo par com alguém no frontend.

Can we ship this to production?

Podemos enviar isso para produção?

Not yet. We need one more approval.

Ainda não. Precisamos de mais uma aprovação.

I added logging. We can trace the issue now.

Adicionei logs. Podemos rastrear o problema agora.

How do we scale this?

Como escalamos isso?

We can add more instances. The load balancer is ready.

Podemos adicionar mais instâncias. O load balancer está pronto.

She is debugging the performance issue.

Ela está depurando o problema de performance.

Did you update the dependencies?

Você atualizou as dependências?

Yes. I ran npm update. No breaking changes.

Sim. Rodei npm update. Sem breaking changes.

We need to add input validation.

Precisamos adicionar validação de entrada.

What database are we using?

Qual banco estamos usando?

PostgreSQL for main. Redis for cache.

PostgreSQL para o principal. Redis para cache.

He created a ticket for the tech debt.

Ele criou um ticket para a dívida técnica.

Is the feature flag enabled?

A feature flag está habilitada?

Yes, for ten percent of users. We will increase slowly.

Sim, para dez por cento dos usuários. Aumentaremos devagar.

We are doing a code freeze until the release.

Estamos em code freeze até o release.

Who wrote this function?

Quem escreveu esta função?

I think Maria did. Check git blame.

Acho que foi a Maria. Confira o git blame.

She suggested we use TypeScript. I agree.

Ela sugeriu usar TypeScript. Concordo.

Do we have a staging environment?

Temos ambiente de homologação?

Yes. We deploy there first. Then production.

Sim. Fazemos deploy lá primeiro. Depois produção.

I am working on the database schema.

Estou trabalhando no schema do banco.

What is the rollback plan?

Qual é o plano de rollback?

We keep the previous version. One command to revert.

Mantemos a versão anterior. Um comando para reverter.

He fixed the memory leak. We can deploy.

Ele corrigiu o vazamento de memória. Podemos fazer deploy.

How do we test this in production?

Como testamos isso em produção?

We use canary releases. Small percentage first.

Usamos canary releases. Pequena porcentagem primeiro.

We need to add error handling.

Precisamos adicionar tratamento de erros.

Did the CI pipeline pass?

O pipeline de CI passou?

Yes, all stages passed. We are good to merge.

Sim, todas as etapas passaram. Podemos fazer merge.

She is the tech lead for this project.

Ela é a tech lead deste projeto.

What is the API contract?

Qual é o contrato da API?

We have an OpenAPI spec. I will share the link.

Temos uma spec OpenAPI. Compartilho o link.

I am adding retry logic for the external call.

Estou adicionando lógica de retry para a chamada externa.

Do we need to update the frontend?

Precisamos atualizar o frontend?

Yes, the response shape changed. I will update the types.

Sim, o formato da resposta mudou. Atualizarei os tipos.

He is doing a spike on the new architecture.

Ele está fazendo um spike na nova arquitetura.

What is the latency like?

Como está a latência?

Under two hundred milliseconds. We are within SLA.

Abaixo de duzentos milissegundos. Dentro do SLA.

We are moving the repo to the new org.

Estamos movendo o repositório para a nova organização.

Can you add a comment to the code?

Pode adicionar um comentário no código?

Sure. I will explain the logic.

Claro. Explicarei a lógica.

She raised a concern about security. We are addressing it.

Ela levantou uma preocupação de segurança. Estamos tratando.

How do we monitor this in production?

Como monitoramos isso em produção?

We have dashboards and alerts. PagerDuty for critical.

Temos dashboards e alertas. PagerDuty para crítico.

I am waiting for the design review.

Estou aguardando a revisão de design.

Did you run the linter?

Você rodou o linter?

Yes. I fixed all the issues.

Sim. Corrigi todos os problemas.

We are considering moving to Kubernetes.

Estamos considerando migrar para Kubernetes.

What is the branch strategy?

Qual é a estratégia de branches?

We use GitFlow. Feature branches from develop.

Usamos GitFlow. Branches de feature a partir da develop.

He is optimizing the query. It was too slow.

Ele está otimizando a query. Estava lenta demais.

Do we have integration tests?

Temos testes de integração?

Yes, we run them in the pipeline. They take five minutes.

Sim, rodamos no pipeline. Levam cinco minutos.

She proposed a new design. We are reviewing it.

Ela propôs um novo design. Estamos revisando.

What is the deadline for this sprint?

Qual é o prazo desta sprint?

Friday. We have three more days.

Sexta. Temos mais três dias.

I need to rebase my branch. Main has changed.

Preciso dar rebase na minha branch. A main mudou.

Can we pair on this bug?

Podemos fazer par neste bug?

Sure. I am free after two. Let us screen share.

Claro. Estou livre depois das duas. Vamos compartilhar tela.

We are doing a post-mortem tomorrow.

Faremos um post-mortem amanhã.

What is the caching strategy?

Qual é a estratégia de cache?

We cache for five minutes. Invalidate on write.

Cacheamos por cinco minutos. Invalidamos na escrita.

He is writing the runbook for the new service.

Ele está escrevendo o runbook do novo serviço.

Do we need to update the API version?

Precisamos atualizar a versão da API?

Yes, we are going to v2. Backward compatible.

Sim, vamos para v2. Retrocompatível.

She is leading the architecture discussion.

Ela está liderando a discussão de arquitetura.
